# Changelog

## 0.1.0 - 2026-05-19

Standalone application implementation:

- added Vite + React + TypeScript Busbar Calculator app;
- added pure domain calculation engine for profile geometry, current density, resistance, losses, steady-state thermal estimate, transient forecast, clearance, channel envelope, and short-circuit checks;
- added dark engineering cockpit UI with inputs, SVG cross-section, temperature chart, short-circuit diagram, warnings, candidate table, calculation trace, PDF export, and JSON/CAD payload actions;
- added example-only material/profile/cooling/clearance datasets with visible warnings and metadata;
- added Vitest coverage for the main calculation pipeline and generated static embed build output.
